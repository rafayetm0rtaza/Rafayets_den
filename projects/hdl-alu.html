The task

Design and implement an 8-bit arithmetic logic unit in hardware description language as part of the ECE 331 digital-systems coursework.

Implementation workflow

The project covered RTL synthesis, functional simulation, and the FPGA implementation workflow in AMD Xilinx Vivado.

What this project demonstrates

Experience moving between an HDL description, a simulated design, and the implementation toolchain. It complements my circuit and microcontroller work with a foundation in digital hardware design.
