Project notes

Inside the build.

Arm Thumb assembly · NVIC · Keil µVision

The task

Control the board’s RGB LED and respond to button inputs using Arm Thumb assembly and direct peripheral-register access.

From clocks to pins

The implementation configures clock gating through SIM_SCGC5, selects pin functions through the PCR MUX fields, and sets direction through PDDR. PSOR, PCOR, and PTOR provide set, clear, and toggle operations for the GPIO outputs.

Interrupt-driven behavior

NVIC priority and enable registers configure the button interrupts. The interrupt service routine handles input events and drives state transitions rather than relying entirely on polling.

Debugging at the memory level

I used Keil µVision memory windows and little-endian byte inspection to examine the machine state while developing the assembly routines.
